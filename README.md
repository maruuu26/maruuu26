## 📌 Featured Project
**Fashion Item Classifier** - CNN based image classifier with live web interface
+ Problem: Give users an instant, interactive way to classify fashion items from an uploaded image instead of manually tagging or searching.
+ What I did: Fine-tuned and deployed a pretrained ResNet-18 CNN, then built a Streamlit interface with a structured prediction database for personalized recommendations and session tracking.
+ Tech Stack: Python, TensorFlow, Streamlit
+ Result: 85%+ accuracy on image datasets, with predictions returned in under 300ms.
